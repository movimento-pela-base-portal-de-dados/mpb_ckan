# Contribuição

- Alterações entram por Pull Request.
- A branch principal deve ser protegida contra push direto.
- CI precisa estar verde antes do merge.
- Segredos não são versionados.
- Mudanças de contrato entre `mpb-ckan`, `mpb-infra` e `mpb-data-pipelines` devem ser documentadas no PR.
- Mudanças arquiteturais relevantes exigem ADR ou aprovação da liderança técnica.
